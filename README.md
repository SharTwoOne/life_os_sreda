# life_os_sreda

Скилл, который разворачивает человеку **его среду для работы с ИИ-агентом** на своём компьютере.
Та же схема, по которой устроена Life OS: один главный файл правил, карта, которая ведёт по
проектам, раздел «Обо мне», цели, правила общения, гейты и память.

Работает в Claude Code. Можно пройти в паре с архитектором (на созвоне) или одному.
Файлы и папки называются по-английски, текст внутри — на языке человека.

---

## Что получится у человека

```
~/anna-os/                     ← папка среды, имя латиницей
├── CLAUDE.md                  ← главный файл: правила и маршрутизация. Агент читает первым
├── map.md                     ← карта: что где лежит. С неё начинается любой запрос
├── data-standard.md           ← как называть файлы, что ставить в шапку
├── intervention-rule.md       ← что агент делает сам, когда зовёт, что всегда делает человек
├── gates.md                   ← проверки «да/нет» перед сдачей работы + личный стоп-лист
├── automations.md             ← что отнимает время и что из этого отдаём агенту
├── about-me/
│   ├── 00-overview.md         ← карта раздела
│   ├── profile.md             ← единый документ: кто, чем живёт, ценности, как думает
│   ├── how-to-talk-to-me.md   ← как надо и как не надо общаться
│   ├── goals.md               ← цели с цифрами и журнал чекинов
│   └── verbatim.md            ← сырьё: живые ответы без правки
├── constitution/              ← фундамент, принципы, проекты, слабые стороны. Пишет сам человек
├── memory/                    ← что агент узнал в работе: решения, поправки, хроника
└── <project>/                 ← папка на каждый проект: свой CLAUDE.md и 00-overview.md
```

## Как запустить

**Вариант 1. Разово, из этой папки.**

```bash
git clone https://github.com/SharTwoOne/life_os_sreda.git
```

```bash
cd life_os_sreda && claude
```

Дальше написать агенту «начни». Он спросит, где создать среду, и поведёт по шагам.

**Вариант 2. Поставить скилл насовсем.** После этого он доступен в любой папке командой `/life-os-sreda`.

```bash
cp -r life_os_sreda/.claude/skills/life-os-sreda ~/.claude/skills/
```

## Три режима

| Режим | Когда | Как идёт |
|---|---|---|
| **Архитектор на созвоне** | Настраиваешь среду другому человеку | Агент подсказывает архитектору следующий вопрос, архитектор спрашивает голосом и вставляет ответы |
| **Расшифровка** | Созвон уже был и записан | Вставляешь расшифровку, агент раскладывает её по файлам и собирает список того, что не прозвучало |
| **Сам** | Человек проходит один | Агент задаёт по одному вопросу и ждёт ответа |

## Что внутри репозитория

| Путь | Что это |
|---|---|
| `.claude/skills/life-os-sreda/SKILL.md` | Сам скилл: порядок работы от первого вопроса до проверки среды |
| `…/references/interview.md` | Вопросы по семи блокам и куда ложится каждый ответ |
| `…/references/environment-rules.md` | Все правила организации среды и зачем каждое. Для архитектора |
| `…/references/automations.md` | Каталог автоматизаций: как узнать по словам человека и с чего начать |
| `…/templates/` | Шаблоны файлов среды, которые скилл раскладывает и заполняет |
| `…/scripts/check.py` | Гейты самой среды: всё ли на месте, нет ли пустых обязательных мест и секретов |
| `…/scripts/connect-memory.py` | Подключает `memory/` к памяти Claude Code, чтобы она читалась в каждой сессии |

## Главные принципы

1. **Только слова человека.** Агент не додумывает ни цифр, ни целей, ни формулировок. Пустое место честнее выдуманного.
2. **Файлы, а не чат.** Всё важное лежит MD-файлами у человека на компьютере и переживёт смену модели и подписки.
3. **Один вход.** Агент всегда начинает с `CLAUDE.md` и `map.md` и не теряется в папках.
4. **Правило и гейт, а не надежда.** Что агенту можно без спроса, записано заранее. Перед сдачей работа проходит проверки «да/нет».

Подробно: [environment-rules.md](.claude/skills/life-os-sreda/references/environment-rules.md).
