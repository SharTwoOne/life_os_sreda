# Каталог автоматизаций

> Как узнать автоматизацию по словам человека и с чего начинать. У каждой строки — сигнал в ответах,
> первая версия за вечер и где агент обязательно зовёт человека.

## Как выбирать первую

1. **Больше всего часов в неделю** — по его оценке, не по твоей.
2. **Самая простая первая версия** — работает на файлах и существующих доступах, без новой инфраструктуры.
3. **Ничего не уходит наружу без человека.** Первая автоматизация делает черновики, а не отправляет.
4. **Результат виден в первый же день.** Если отдача через месяц — это не первая.

## Как записать кандидата в `automations.md`

```
### <Название его словами>
- Сейчас: что делает руками · сколько часов в неделю (его цифра)
- Агент будет: …
- Зовёт человека: …
- Первая версия: … · сложность: вечер / неделя / месяц
- Статус: кандидат / первая / в работе / работает / отказались (почему)
```

## Красные флаги

- Автоматизация **отправляет** что-то людям с первого дня — нет. Сначала черновики.
- Нужны пароли от чужих систем — вводит человек сам, в файлы не пишутся.
- «Сделаем всё сразу» — одна автоматизация за раз. Следующая — когда первая проработала неделю.
