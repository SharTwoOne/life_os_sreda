# Стандарт данных

> Как называются файлы и папки, что стоит в шапке, какие бывают метки.
> Один стандарт на всю среду. Завёл файл — сверься отсюда.

## Принцип

**Имя файла — английское и короткое, смысл — в шапке.** Имя нужно, чтобы путь не ломался
в терминале, скриптах и ссылках. Как документ называется по-человечески — поле `name:`.

## 1. Имена файлов

| Класс | Что это | Правило | Пример |
|---|---|---|---|
| **Документ** | Правила, гайды, карты, досье | `kebab-case.md`: английский, строчные, дефисы | `how-to-talk-to-me.md` |
| **Поток** | Копится день за днём: созвоны, сессии, выпуски | `YYYY-MM-DD-slug.md` | `2026-09-10-call-anna.md` |
| **Служебное** | Читает только машина: скрипты, конфиги | Так же, латиницей | `build-report.py` |

- У потока дата впереди: сортировка по имени становится сортировкой по времени.
- Карта раздела внутри любой папки — `00-overview.md`. Агент, зайдя в папку, читает её первой.
- Не пишем тип и область в имя — для этого метки и папки.
- **Не переименовываем без нужды:** на имена завязаны ссылки.
- Имена, которых требует инструмент, не трогаем: `CLAUDE.md`, `SKILL.md`, `memory/MEMORY.md`.

## 2. Имена папок

Английские, строчные, через дефис, без даты: `clients`, `content`, `bakery-shop`.
Папки-потоки (события) — с датой впереди: `2026-09-10-launch`.
**Пустых папок не держим**: папка появляется вместе с первым файлом.

## 3. Шапка

```yaml
---
name: Как со мной говорить
tags: [canon, me, voice]
обновлён: 2026-09-10
---
```

| Поле | Обязательно | Что туда |
|---|---|---|
| `name` | да | Название для человека, на его языке |
| `tags` | да | 2–5 меток из словаря ниже |
| `обновлён` | да | `ГГГГ-ММ-ДД`. Правишь смысл — двигай дату |
| `статус` | нет | `черновик` / `в работе` |
| `люди` | нет | Кого касается: ники в мессенджере, `[anna_k, ivan_p]`. Ник — ключ человека, имя им быть не может |

## 4. Словарь меток

**Закрытый.** Новая метка сначала вписывается сюда, потом используется.
Порядок в строке: тип → область → материя.

**Тип (ровно одна):** `rules` правила · `map` карта, индекс · `canon` источник истины, эталон ·
`guide` как делать · `plan` план, черновик · `corpus` живые тексты, сырьё · `memory` память агента ·
`log` журнал · `people` карточка человека · `reference` разбор чужого

**Область (одна, `me` может стоять второй):** `system` про саму среду · `me` про {{ИМЯ}} ·
{{ОБЛАСТИ_ПРОЕКТОВ}}

**Материя (сколько нужно):** `voice` голос и тон · `text` тексты · `design` оформление ·
`image` картинки · `video` видео · `prompt` промпты · `money` деньги · `idea` идеи

## 5. Связи

В тексте ставим `[[двойные скобки]]` на связанные файлы. Папки дают иерархию по месту,
связи — по смыслу. Ссылка на ещё не написанный файл — нормально: это заявка.

## 6. Завёл файл — чек-лист

1. Класс имени: документ, поток или служебное. Имя английское
2. Шапка: `name`, `tags`, `обновлён`
3. Папка по смыслу
4. `[[связи]]` на соседние документы
5. Новый раздел — `00-overview.md` и строка в `map.md`
